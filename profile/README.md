# Gentoo-zh 社区

2003 年起于中文 Gentoo Linux 用户社区，现在服务所有 Gentoo 用户。

## Overlay

[gentoo-zh](https://github.com/gentoo-zh/overlay) 是一个 `masters = gentoo` 的 overlay，收录 490 多个软件包。

```
eselect repository enable gentoo-zh
emaint sync
```

中国大陆镜像加速：https://gentoozh.org/overlay/
distfiles 与预编译二进制包：https://distfiles.gentoozh.org
